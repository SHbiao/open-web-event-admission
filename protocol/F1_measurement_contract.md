## Phase isolation

`prepare` reads the A package and frozen manifests and writes 102 label-blind inputs; it does not read or hash Gold. `replay-self-check` reads only historical DEV/EVAL caches and runs synthetic checks. `semantic`, `retrieve`, `rerank`, and `freeze-predictions` are label blind. `score` is the only function that reads Q0 Gold and requires a separate main-agent F2 release file. `verify` checks prediction/cache/scoring-artifact hashes and recomputes metrics from the immutable scoring audit; it does not reopen Gold or change predictions. F1 executed only `prepare` and `replay-self-check`; all other stages remain unexecuted.

The frozen prediction schema contains one row per item: item ID and evidence hash, generator/candidate/retrieval/rerank status and failure reason, candidate count/coverage, all eight methods' `score_status`, numeric score or JSON null, fixed threshold, decision (`ADMIT`, `NOT_ADMIT`, `ABSTAIN`) and boolean `accepted`, all 20 primary feature keys (null when unavailable), six clean feature keys, and an output manifest with input/cache/source/model/resource/prompt hashes. It contains no A/B/C/Gold label or correctness field. A one-row-per-item invariant and exact cache query-set checks are mandatory.

## Failures and denominators

Every item stays in the 102-item coverage denominator and in its full Gold class denominator for Retention/FAR. Supported statuses are `OK`, `NO_CANDIDATE`, `INVALID_JSON`, `INVALID_SCHEMA`, `INVALID_SPANS`, `GENERATION_LIMIT`, `MODEL_ERROR`, `RETRIEVAL_ERROR`, `RERANK_ERROR`, `MISSING_SCORE`, `NONFINITE_SCORE`. A missing or nonfinite score gives JSON null and `ABSTAIN`; operationally it is not accepted, but it is not a predicted Gold REJECT. No 0, -20, minimum or mean value substitutes for missing data. Partial exact candidates can score despite an extraction warning; the warning and `generator_error=1` remain. Primary requires at least one valid candidate and all 20 legal features; validity requires a valid candidate. Full-item BM25/BGE, direct admission and clean controls retain their independent failure/coverage paths. Old historical sentinels are used only in replay of already frozen historical feature rows, never in D2 prediction.

`ADMISSIBLE` is positive. Primary fixed metrics are ROC-AUC (`roc_auc_score`), AUPRC (`average_precision_score`), Admission Retention = accepted ADMISSIBLE / all Gold ADMISSIBLE, REJECT FAR = accepted REJECT / all Gold REJECT, score coverage, candidate coverage, no-candidate rate and named failure counts/rates. Missing scores remain non-admission at every point on the descriptive Retention--FAR curve; the curve cannot select a new threshold. If score coverage is below 102/102, full-set AUC/AUPRC are `NA_NOT_FULL_COVERAGE`; optional conditional values must show `n_valid`, both class denominators and coverage. Target- and mention-level performance are `NA_NOT_ESTIMABLE_NO_*_GOLD`; item acceptance cannot be called correct-target retention, and no NEW Retention or link accuracy may be inferred.

Intervals: 2,000 paired bootstrap draws, seed `20260928`, stratified by Gold class and sampled in content-cluster units. All methods share the same draws. The cluster key is preregistered from `private/selection_manifest.csv`: normalized external URL when present, otherwise normalized body SHA. This key is available for all 102 items; in this D2 sample it yields 102 distinct clusters. Interval interpretation is conditional on this challenge set, not the Web population. No D2-based threshold, feature, prompt or model selection is allowed.

Only after separate F2 release may `score` open Q0 Gold, join by unique `item_id`, verify all 102, calculate metrics and intervals, and save its output. A non-released score command errors before Gold access. F2 remains blocked at F1 handoff.
