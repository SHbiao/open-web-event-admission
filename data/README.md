# Data release scope

The benchmark has three evidence layers: P0 task-unit calibration, DEV30/EVAL60 controlled diagnostics, and a 102-item D2 challenge confirmation set. They must not be concatenated into one homogeneous test set.

This public package intentionally contains no raw item text, external URLs, source identifiers, A/B annotation packages, human adjudication records, or fused Gold labels. Those artifacts remain in the private research archive because of privacy, licensing, and reproducibility-boundary considerations.

The public aggregate file in `../results/d2_aggregate_metrics.csv` is sufficient to inspect the reported denominators and headline metrics without reconstructing or identifying individual posts. Researchers who need item-level access should contact the authors and provide an ethics, licensing, and data-protection plan.
